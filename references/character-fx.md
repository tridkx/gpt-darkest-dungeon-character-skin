# DD1 角色与技能特效

用于制作或返修皮肤配套视觉 FX。方法来自强盗最小包；其他职业读取自己的原版文件，不直接套文件名、挂点或时间参数。

## 路线选择

| 需求 | 实现 | 实测范围 |
| --- | --- | --- |
| 静态剑刃、符文亮边 | 绘入人物 RGBA 图，随人物附件显示 | 剑刃亮边可见，不是动态场景照明 |
| 符环等独立运动层 | 人物骨架新增专用骨骼与独立 slot，配运动和透明度时间线；绘制顺序控制前后层级 | 符环可见，旋转和明暗周期尚未逐项验收 |
| 技能施放效果 | 独立 FX 三件资源，职业美术配置 `.fx` 引用 | 独立枪口爆闪可见 |
| 目标命中效果 | 独立 FX，`.targchestfx` 引用，定位到目标胸部 | 放大后的命中环可见，其他目标挂点未测 |

光点可用多个独立 slot 复用同一图集区域，配骨骼位移、缩小及透明度变化。这是贴图加骨骼运动，不代表验证了复杂粒子系统、特殊混合模式或实时照明。

## 资源与调用

强盗公共人物骨架放在 `heroes/highwayman/anim/`，人物 PNG 放在 `heroes/highwayman/highwayman_<皮肤字母>/anim/`。独立技能 FX 的三件资源放在 `heroes/highwayman/fx/`，PNG 不放入皮肤字母目录。

已实测的命名关系：

```text
施放：heroes/highwayman/fx/highwayman.sprite.codex_probe_muzzle.{skel,atlas,png}
骨架动画名：codex_probe_muzzle
美术配置：.fx "codex_probe_muzzle"

目标：heroes/highwayman/fx/highwayman.sprite.codex_probe_impact.{skel,atlas,png}
骨架动画名：codex_probe_impact
美术配置：.targchestfx "codex_probe_impact"
```

图集页名指向对应 PNG。独立 FX 使用自己的 `root`、`fxskill` 及特效子骨骼。施放端按人物图枪口/武器像素位置、地面锚点和世界比例计算子骨骼位置；目标端不要误用施放端的枪口偏移。本实例目标图层位于 FX 原点附近，接入 `.targchestfx`。

保留原版 `.art.darkest` 其他内容，只改目标技能的引用；使用项目专属资源名避免覆盖原版 FX。最小包只改 `pistol_shot` 的 `.fx` 和 `.targchestfx`，不提供 `.info.darkest`，数值沿用游戏。美术配置是职业公共文件，新资源名不能消除与其他修改此文件的 Mod 的覆盖冲突。

人物状态可能被多个技能共用，如 `attack_pistol`。更换状态会影响其他技能的姿势，原版 FX 也可能自带人物轮廓。最小实验可只覆盖战斗待机和一个攻击状态，但须说明未覆盖状态仍显示原版人物，以及配套皮肤字母和其他皮肤兼容范围。

## 动画与离线检查

- 使用固定版本转换器生成 Spine 2.1.27；每 slot 一个 attachment，避免同槽换图。符环、人物呼吸和公共 FX 挂点分别处理。
- 动画开始明确设置可见性，独立 FX 终点全部隐藏；再次播放要能恢复。先沿用对应原版 FX 的总持续时间，再调整其中可见区间。
- 保留公开人物动画名、公共 FX 骨骼及祖先的父级/变换、所需声音事件；独立 FX 动画名与调用对应。
- 源图普通 RGBA、安装图预乘 Alpha；检查图集边界、区域尺寸、附件缩放、PNG 路径及各皮肤配套贴图。
- 二进制回读核对运动/颜色时间线、附件参数和终点透明度，预览从回读数据渲染。正常重建保留手工 JSON，显式重生成时才覆盖。

## 短窗口下看不到命中效果

触发条件：枪口效果可见，目标效果未观察到。不能只凭相同格式推断目标通过；先核对技能命中、调用名、资源路径、动画名、目标挂点及遮挡，再检查可见窗口。

有效诊断实例：目标图块世界宽度从 115 增至 230，骨骼起始缩放从 0.25 改为 1，第 0 秒完全显示，保持至 1.6 秒，1.95 秒透明度归零；总持续时间仍约 2.033 秒。目标光点同步提前并延长。调整后用户确认看到了命中环。

这些参数用于提高短窗口可观察性，不是其他职业的固定规范。此次同时改变大小、起始时刻和可见区间，不能认定其中某一项单独就是原先未看到的原因。延长 FX 时间线不保证延长游戏攻击镜头。

## 灰白色与滤镜

触发条件：源图/离线预览有青色，游戏中剑刃和符环呈灰白色。先查实际安装 PNG 色彩、是否重复预乘、骨架 RGB 乘色及其他 Mod 覆盖，不直接归因于滤镜或连续重绘。

本实例图集保留青色，RGB 乘色为白色、仅调整透明度。本机 `character.glsl` 有角色 LUT 与光照，`film.glsl` 有火把/演出 LUT，`sprite_premult.glsl` 有去饱和混合；证明机制存在，未证明灰白色具体成因。可在高火把、选中/未选中等状态对照定位。

独立 slot 不等于独立 shader，目前未找到并验证单个皮肤或 slot 跳过调色的配置。部分去饱和可尝试色彩补偿，完全去色不能仅靠提高贴图饱和度恢复。替换 LUT/shader 是潜在全局实验，可能影响其他角色或场景，尚未验证；Windows 还有编译 HLSL `.wbc`，不保证修改 GLSL 一定作用于实际后端。本次未修改 shader/LUT。
